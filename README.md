# NEUROFORGE SYSTEMS

Landing page concept for Neuroforge Systems.

## Local preview
Open `index.html` in a browser or serve the repository root with a static web server.

## Hero video
The page is already configured to play the supplied intro clip as a muted, looping, full-bleed hero background. Add the video file at:

`assets/neuroforge-intro.mp4`

The file is referenced by `index.html`. The video should be encoded as H.264 MP4 and include no audio track (the page is designed as a silent ambient background). If no video is present, the dark cyan/green gradient remains as a visual fallback.

## Scope
The module descriptions and architecture on the site are a proposed product concept, not claims that those systems are already implemented. Update each module's status as features are built and tested.
